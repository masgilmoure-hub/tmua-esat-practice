## 交付与使用

“官方历年卷 → 2022”可选单卷 20 题或两卷 40 题，每卷独立 75 分钟、提交后锁定。题库按年份、试卷、知识点、细分考点与难度筛选后，可自由组专项练习。原始题号、链接与稳定 ID 沿用此前档案；原有记录快照不被改写。

全部题干和实际选项为英文文字及 LaTeX，提供本站独立编写的中英对应解析、易错点和教学难度。四幅复杂图形直接裁取原卷：P1 第 4 / 17 题、P2 第 11 / 18 题。查看大图使用原始像素并在手机弹窗内滚动；关闭或按 Escape 保留答案，限时练习持续计时。

答案字母逐题独立录入后与官方索引比较：

- Paper 1：`CDFCHFEBECADADHBDBFB`
- Paper 2：`BECBFCFCAGCFEDFDEEBE`

Paper 1 考点分布：代数 1、微积分 4、函数 5、几何 4、概率 1、数列与级数 3、三角函数 2。Paper 2：代数 2、微积分 2、函数 3、几何 3、逻辑与证明 10。教学难度并非官方标定。

## 可复用流程

在仓库根目录运行，需 Python、Poppler（`pdftotext` / `pdftoppm`）、Node ≥22.13 和项目依赖：

```sh
python scripts/prepare-native-papers.py 2022 /tmp/tmua-2022-trial
node --experimental-strip-types scripts/assemble-native-paper.ts 2022 p1 /tmp/tmua-2022-trial/p1-drafts.json src/data/tmua-2022-p1.json
node --experimental-strip-types scripts/assemble-native-paper.ts 2022 p2 /tmp/tmua-2022-trial/p2-drafts.json src/data/tmua-2022-p2.json
npm test
npm run build
npm run test:e2e
```

准备工具先核对两份原卷与两份英文详解的 SHA-256，再整卷提取文本与题目页图，使用两个工作线程处理独立文件。`preparation.json` 记录来源哈希、提取参数和页码；相同输入且输出存在时复用，重复运行实测 4/4 任务命中。缓存是编辑工作区，不会自动加入网站。改变图片或文本后仍需编辑复核，缓存存在性检查不等于内容审校。

人工将文本对照原页修正，独立求解、核对答案，编写双语解析与细分考点，再准备每卷 20 个顺序草稿。草稿字段如下；临时草稿位于上述 `/tmp` 目录，发布数据才纳入仓库。

| 草稿字段 | 含义 |
| --- | --- |
| `number` / `reviewed` | 原题号 1–20、编辑声明已复核 |
| `answer` | 独立录入的正确字母，不由装配器填入 |
| `topic` / `subtopic` | 共享知识点 ID、`[细分ID, 中文名称, 英文名称]` |
| `prompt` / `options` | 原始英文题干与实际选项，明确的 LaTeX 分隔符 |
| `steps` / `pitfall` | 步骤数组，每步为 `[中文, 英文]`；易错点也是双语对 |
| `difficulty` / `diagram` | 教学难度、可选原图路径与英文描述 |

装配器复用统一来源 / 年份 / 原题号 / 稳定 ID 和考点模板，检查答案一致性、完整题数、双语结构、共享题库规范、每个公式的 KaTeX 可解析性与图片存在性。失败不会覆盖原输出。`reviewed: true` 只是编辑声明，自动检查不能证明数学推理正确或图片完整。

## 实际发现与修正

- 提取文本不能直接发布：P1 第 5 / 9 题有符号或根号漏识别，P2 第 14 题绝对值符号不完整。均对照原页恢复。
- P1 第 16 题官方详解末尾多项式有笔误，本站解析用等价变量替换独立推导，得到正确的 `7x⁴−8x²+2=0`，答案仍为 B。
- P1 第 18 题保留官方选项 B 的五个符号变化区间证明，并说明 `r=2` 的边界补充，不将选项 B 宣称为所有可能参数的完整集合。
- P1 第 20 题先核对两边非负，再等价平方并因式分解，完整区分交点数 1 / 3 / 4，无需重画复杂图像。
- P2 第 18 题的定义域为开区间，解析使用端点极限与内部取值，避免定义 `0^0`。原选项表转换为逐项带函数名称的文字选项，保留列顺序和图形 P / Q / R / S。
- 原图第一轮裁剪过紧，目视检查发现下方坐标分母被截断。已扩展裁剪边界、重新构建并复测两项 2022 浏览器流程；所有刻度完整。

这些发现支持保留逐题内容与视觉复核。节省来自整卷准备、元数据复用、共享检查和批量验收，不能通过省略复核来压缩时间。
