# TMUA 官方历年原卷与站内答题卡

核实日期：2026-10-11。官方资料库 <https://esat-tmua.ac.uk/tmua-preparation-materials/> 当前公开 TMUA 2016–2023 年 Paper 1 / Paper 2、各卷英文 worked answers 和每年的 answer keys。官网说明这些历史试卷可用于当前 TMUA 备考；本次不使用未公开近期试题或第三方回忆版。

## 已接入材料与实际操作

- 8 个年份、16 份原卷、16 份英文详解、8 份答案表，共 320 个经过核实的事实答案条目。
- 从“官方历年卷”或题库中的入口进入，选择年份与单卷 / 两卷。先打开官方 PDF 确认可读，再开始答题卡。
- 在官方原卷阅读题干、实际选项和图表，在本站按原始题号选择字母。答题卡统一使用 A–H 槽位；每题实际可选范围以原卷为准。
- 限时模式每卷完整 20 题、75 分钟；也可不限时。两卷独立计时，提交后锁定，超时自动提交；过渡页时间不计入答题用时。
- 结果提供答对 / 总数、正确率、用时、未答和分卷结果；逐题显示提交答案、官方正确字母以及原卷 / 官方英文详解 / 答案表链接。
- 刷新续做、标记待检查、本地记录、错题本与重练继续使用现有存储。记录仍不跨设备同步，不换算官方 1–9 分。

## 题干未在本站转录的原因

官方 [Website terms of use](https://esat-tmua.ac.uk/website-terms-of-use/) 的 Intellectual Property 段将下载材料的使用限于个人用途，限制商业再利用和修改，同时明确允许公平、合法的链接并要求承认作者身份。因此公开下载不能直接作为把整套题干、选项、图表和官方解答复制到学生网站的授权。

本次实现保留官方原始 PDF 的外链，只将材料名称、年份、原始题号、答案字母等事实索引及自主编写的界面说明保存到项目；不复制、重新托管或拆分原卷图表，也不冒充官方软件或机构背书。原作者为 Cambridge Assessment / Cambridge University Press & Assessment，公开入口由 UAT-UK 提供；页面明确标注来源和无隶属 / 背书关系。

这不是题干已导入站内的完整交互题库。320 个答题条目不参与原有按知识点 / 细分考点筛选，也不声称有逐题难度、知识点标签、中文数学解析或易错点。外部原卷结果不显示知识点表现或推荐训练，避免将整卷混合内容误当作一个知识点。现有 21 道原创示例的完整双语解析流程仍可使用。

后续将原题转录到站内需要适用的再发布授权，之后再逐题复核题干、选项、数学格式、图表、答案、标签及自主编写的双语解析。不能只填答案字母并将其称作“完整解析”。

## 数据与复核

`src/data/past-papers.json` 保存来源链接、文件 SHA-256 和按原始题号排列的 20 个答案字母。`src/data/pastPapers.ts` 在开始练习时生成明确标记 `external.kind = linked-paper` 的题号引用快照，并创建 75 分钟分卷计划。题干字段只含自主编写的英文阅读指示；选项字段仅是 A–H 字母。结果页专门渲染外部原卷引用，不把通用阅读提示显示为数学解析。

```sh
# 需要 Python 3、Poppler 的 pdftotext，以及访问官方 HTTPS 来源
python3 scripts/verify-past-papers.py
```

复核脚本通过保留 TLS 校验的 HTTPS 读取 40 份官方 PDF，核对文件类型与 SHA-256，再从 8 份答案表提取两个 1–20 题序列，与已保存的 320 个字母逐个比较。2018 / 2019 年为上下排列，其他年份为并排两栏；均明确检查编号顺序。官方文件若在同一 URL 发生变化，脚本失败并要求重新人工复核，不自动更新校验值或答案。

下载内容只保存在临时目录用于验证，完成后删除；仓库和网站构建产物不包含官方 PDF 或其题干文本。前端运行不需要 Python / pdftotext，这些工具仅用于开发时复核。

## 发布与访问限制

本轮 GitHub 提交与本地可操作预览包含此功能；Sites 当前已发布版本不会随 GitHub main 自动更新，需另行发布。在新标签页打开官方 PDF 需要学生网络可访问原始 HTTPS 地址，页面预检由学生确认。云端文件获取成功不代表已验证每位学生的网络、Safari 原生 PDF 阅读器或手机阅读体验；建议电脑 / 平板并排阅读。本站只测试了链接属性和站内实际答题流程，未声称完整模拟 Pearson 现行考场软件。
