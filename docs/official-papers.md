# 用户资料包与 TMUA 站内原卷题库

2026-10-12 已接入用户上传的 `TMUA_官方题库_2016-2023及早期样卷.zip`。这是面向用户个人实验的版本，本轮不重新发布公开 Sites 网址。

## 当前内容

资料包共 45 份 PDF：2016–2023 每年两卷、两份逐题英文解答与一份答案表，另有早期样卷的五份文件。已接入 2016–2023 年 16 份原卷、16 份解答及 320 个题号；早期样卷尚未导入，不混入历年题统计。2016 原卷封面为 Practice paper，保留这种原始材料性质，不称为当年实际考试场次。

题库当前包含 **21 道原创示例 + 320 个原卷题目条目**。选择来源“官方公开材料”可找到 320 题，单题练习会在答题页直接渲染对应原卷页。也可从“官方历年卷”选择年份、单卷 / 两卷，按每卷 20 题、75 分钟或不限时练习。答题卡 A–H 是统一槽位，实际可选范围以原卷为准。

原题以 PDF 保持英文题干、选项、公式和图表原貌；它们尚未转换为可编辑的结构化题干。2016 年 PDF 文本编码会产生乱码和拆分题号，所以使用原卷渲染避免错误数学符号。题号映射完整覆盖 320 条；2016 年部分页有两题，定位到所在页后可在阅读器中滚动。

逐题知识点、细分考点、难度和双语数学解析尚未审校。官方题在这些筛选中归入“原卷考点未逐题标注”及“未标注”难度；结果不推测知识点掌握程度，也不把通用阅读提示当作完整解析。交卷后可打开项目内对应官方英文解答 PDF。原创示例仍有完整双语解析和易错点。

## 文件与导入复核

```sh
python3 scripts/import-user-papers.py /path/to/user-archive.zip
```

需要 Python 3 和 Poppler `pdftotext`。脚本只读取明确指定的资料路径，不执行包内说明、HTML 或其他指令，不按 ZIP 内任意路径写文件。限制文件总量、体积，并逐一比对原卷 / 解答 / 答案表的 SHA-256 与已核实来源。320 个上传答案已与现有事实索引逐项核对一致。

全部文件和页码通过校验后，才写入 `public/papers/` 的 32 份 PDF 与 `src/data/local-papers.json`。页码映射由布局位置提取，处理旧字体数字和相邻拆分数字；16 卷所有 1–20 题号均已定位。原始官方链接、题号、年份与校验值仍保留在 `src/data/past-papers.json`，不会因为本地文件名变化而重编号。

原作者和公开来源：Cambridge Assessment / Cambridge University Press & Assessment，UAT-UK 官方资料库 <https://esat-tmua.ac.uk/tmua-preparation-materials/>。本项目无机构隶属或背书关系。导入源是用户在本对话实际提供的资料包；仓库仍为用户原有私有 GitHub 仓库。

## 阅读器与本地保存

- 默认从项目内置原卷加载，无需打开外部网站；PDF.js 渲染到画布。
- 题号变化自动翻到对应页。可手动翻页、缩放、修正本题页码。
- 支持上传本地 PDF，最多 20 MB / 500 页。文件与已核实原卷校验值不一致时明确提示；判分继续使用所选官方卷的答案，不会偷偷改答案索引。
- 个性上传和校正使用独立 IndexedDB `tmua-esat-files:v1`，仅当前浏览器保存，不上传服务器或同步到其他设备。
- 移除本地 PDF 需确认，恢复内置原卷，不删除答案、练习记录或错题。存储不可用时原卷仍可阅读，个性上传仅在页面内保留并明确提示。
- 无效 PDF 不覆盖之前保存的文件。加密、超大或无法渲染的文件提供可操作错误状态。画布大小有上限，翻页或离开时取消旧渲染和释放文档。

内置原卷是项目静态资源，个性上传才是浏览器本地资源；本版没有正式账号、服务器权限或跨设备同步。目录名 `public` 是 Vite 的静态资源约定。本轮按个人实验范围保存代码和私有材料，不更新公开 Sites 部署。

## 预览

正常站点有主脚本、PDF worker 和原卷静态文件。单文件预览额外嵌入 PDF worker 与 32 份 PDF，约 23 MB；经过 HTTP 服务测试，无外部资源请求也能读取原卷、作答与判分。主脚本为兼容便携预览使用单一构建，Vite 会提示约 790 KB 的主块；worker 仅进入阅读器时启用。后续规模扩大可单独优化部署构建的分块。

单文件预览的 `file://` 行为仍受浏览器与机构策略影响；正式稳定保存推荐 HTTP(S)。Safari / Firefox 和屏幕阅读器整套体验未验证。
