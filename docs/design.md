# 界面设计约定

原型采用 Image Gen 生成的题库、答题与复盘概念，概念文件保留于 `/workspace/generated_images/`（不作为网页 UI 图片）。

- 背景纯白 `#ffffff`，正文 `#19273b`，次要文字 `#667085`，主色 `#315bea`，边框 `#dee3eb`，浅色区 `#f5f7fb`，提醒采用浅琥珀色。
- 桌面 76px 顶部导航，主区最大 1380px，左右两栏约 3:1，28px 间距；移动端导航可横向滚动、内容上下堆叠。
- 字体为系统中英文 sans-serif；标题 32–36px、题干 22–24px，控件与正文 14–16px；框半径 10px，控件半径 6px。
- 组件：顶部导航、考试切换、筛选按钮行、题目列表、训练设置、答题选项、计时横条、题号导航、提交确认、结果指标、知识点条形表现、解析段落。
- 图标使用 Lucide 细线风格：BookOpen、ArrowRight、ChevronLeft/Right、Clock、Flag、Info、AlertCircle、Check、X、Save、RotateCcw、Trash2。
- 无背景插画、渐变、装饰性标签或虚构成绩。全部题干、控件、图表和文字由代码渲染。
- 按用户要求增加示例声明、原始来源、未跨设备同步说明、考试规则核实状态；这些为必要的内容扩展。

首屏文字范围：品牌、四个功能入口、中英切换、本地保存说明、主标题和说明、原创示例声明、考试/试卷/知识点/细分考点/来源/状态、题目列表、专项训练设置和考试结构。训练、模考、结果与记录延续同一视觉系统。
