## 如何使用

- **整卷**：官方历年卷 → 2023 → Paper 1 → 勾选准备开始 → 开始真题整卷练习。默认 20 题 / 75 分钟，按原题顺序，也可选择不限时。题干和选项直接显示，不需要打开 PDF。
- **专项**：题库 → 来源“官方公开材料” → 年份“2023” → 作答方式“文字题 · 直接作答”，得到全部 20 题；再选择知识点 / 细分考点 / 难度 / 做题状态。选择题数和限时设置，随机组题且不重复。
- **复盘**：交卷后查看原始答对数、正确率、未答数、用时、知识点表现、正确选项、全部选项、中文 / 英文 / 中英对照步骤和易错点。可重练本次错题，或去练习记录的错题本单题重练；答对后从错题本移出。

- `format: "latex"` 指定显式数学片段，KaTeX 渲染；普通文字与既有 Unicode 示例保持原样。可信 HTML / 外链指令禁用，无法解析的公式显示原式。题干始终英文；题库预览、答题、解析和错题本使用同一渲染组件。
