# 题库结构与后续导入

核心接口位于 `src/types.ts`，当前原创题位于 `src/data/questions.ts`。可导入的独立原创示例位于 `examples/local-import-demo.json`。`examples/question-bank.json` 是内置题的数据结构示例，其 ID 已存在，不能再次导入。题库页面的“管理本地题库”提供 JSON 文件 / 粘贴、校验预览、复核确认、导出与移除；没有 PDF 自动识别。

```sh
npm run validate:bank -- examples/local-import-demo.json
```

导入容器为 `{ "schemaVersion": 1, "questions": [...] }`。校验器检查必填字段、唯一 ID、有效选项/答案下标、双语步骤对应和HTTP(S) 来源 URL 格式（不接受凭据和脚本地址）。不会代替教师进行数学/科学内容审校，也不会自行访问或确认材料的授权。

| 字段 | 约定 |
| --- | --- |
| `id` | 永久唯一的稳定 ID，仅字母、数字、下划线、连字符；不要因排序变化重编号 |
| `exam` | `TMUA` / `ESAT` |
| `moduleId` | `p1`, `p2`, `m1`, `m2`, `biology`, `chemistry`, `physics` |
| `topic` / `subtopic` | 稳定 ID 与 `zh`、`en` 标签；建议另建官方考纲代码映射 |
| `prompt` / `options` | 始终英文；默认纯文本。`format: "latex"` 时识别 `$...$` 行内与 `$$...$$` 展示公式 |
| `format` | 可选且仅接受 `latex`；KaTeX 禁用可信 HTML / 外链命令，解析失败显示原公式 |
| `diagram` | 可选 `{ path, alt }`；path 仅接受 `question-images/文件名.png`，alt 为非空英文图像描述；文件须随构建提供，JSON 不上传图像 |
| `difficulty` | 可选 `foundation` / `standard` / `challenge`；缺省为未标注。教学估计，非官方难度 |
| `correctIndex` | 从 0 开始；A = 0，B = 1 |
| `explanation` | `zh`、`en` 分别含步骤数组与易错点，步骤数对应 |
| `source.kind` | `original-demo` / `official-public`，不得将示例改标官方 |
| `source.title` | 原始材料名称，中英标签 |
| `source.url` | 官方原始材料 URL；原创示例为 `null`，官方公开材料必须有 HTTP(S) 链接 |
| `source.originalNumber` | 原始试卷上的题号，原样保留；示例使用 `DEMO-` 前缀 |
| `source.year` | 原始材料年份；示例为 `null` |
| `source.rightsNote` | 材料来源、授权/使用说明；有必要时加入版本信息 |

## 浏览器导入流程与边界

1. 下载原创示例模板或使用上述格式准备 JSON，保留材料的原始链接、年份和题号。
2. 教师复核题干、选项、正确答案、两种语言的步骤与易错点、考纲标签和使用条件。
3. 在题库展开“管理本地题库”，选择文件或粘贴 JSON，点击“校验并预览”。仅校验不会添加题目。
4. 查看前 5 道题的来源声明、原始题号、难度与使用说明，勾选已复核，再确认导入。
5. 题目可用于本浏览器的筛选和专项训练，刷新后保留；用“导出已导入题目”备份或人工传给其他浏览器导入。

浏览器与 CLI 使用同一个校验器 `src/questionBank.ts`。CLI 独立校验文件；页面还会对照现有题库检查重复 ID 和“考试 + 模块 + 来源种类 + URL/原材料英文名 + 年份 + 原始题号”，拒绝覆盖。同一考试的知识点 ID 必须有一致中英标签，细分考点 ID 必须有一致归属和标签。数组中任何一题失败都拒绝整批，不会部分导入。

导入题库存储键为 `tmua-esat-bank:v1`，与练习记录 `tmua-esat-practice:v1` 分开。累计最多 500 道、1 MB；浏览器总存储额度另有限制。保存成功才更新界面，配额或禁用错误不会添加未保存的题目。损坏或未来版本原数据不会自动覆盖，须明确确认移除后恢复。这里不处理多标签页同时修改冲突。

**导入只更新当前浏览器，不会改变 GitHub、Sites 或其他学生的题库；导出不包含学生成绩。** 想让所有学生得到相同题库，需将审核后的数据纳入项目并重新发布，或后续开发服务端教师题库。清空练习记录会保留导入题；移除导入题会保留内置示例、未完成练习和历史记录。

题库、答题、结果和错题页面按每题来源展示。`official-public` 是文件的来源声明，不是工具对官方身份的认证，必须保留原始 URL 并由教师核实。不要把原创示例改标官方。“示例模考”仍只使用内置原创示例，导入题不会扩大它的题量。“官方历年卷”的 2023 Paper 1 使用内置的 20 道文字题、完整 75 分钟；其他卷仍使用 PDF 答题卡。

结果保存完整题目快照，历史题干、答案和解析不随题库移除而丢失。错题本按最近一次提交更新，已移除题目使用最近的历史快照继续重练，答对后移出。旧 v1 记录未包含难度时可继续读取并归为未标注。

下一步训练以本次错题 / 未答按同试卷或模块、同知识点分组，优先选当前题库中未做题，然后用本次错题补足，最多 3 道，不重复；暂无新题则重练错题。没有分数预测或“已掌握”分类，小样本只描述本次表现。

## 后续账号与教师端

将本地存储层替换为服务端仓库接口：`Student`、`Class`、`Assignment`、`Attempt`、`AttemptAnswer`、`QuestionVersion`。成绩由服务端计算；学生/教师按班级授权访问。教师布置作业需保存题目版本、限时、截止时间、提交策略，避免修改题库导致旧作业成绩变化。客户端原型不是考试安全或防作弊边界，正式版本的答案应在受控交卷后由服务端提供。

## 站内官方原卷条目

当前内置题库合并 21 道原创示例与 320 个已核实的官方原卷题号条目。原始来源、答案和稳定 ID 见 `src/data/pastPapers.ts`；用户提供的 PDF 文件与页码索引见 `public/papers/` 和 `src/data/local-papers.json`。原卷条目保留 `external` 类型区分，题干字段是英文阅读指示，实际题干、选项与图表由原卷画布显示。

官方条目未审校的难度 / 考点显示为未标注，不产生知识点推荐或“完整双语解析”声明。JSON 导入与内置 341 条题目一起检查重复 ID 和原始来源题号。既有 v1 记录仍能读取。用户个性 PDF 与页码修正单独存储在 IndexedDB，不混入练习记录或 JSON 题库导出。更多操作与验证见 [站内原卷说明](official-papers.md)。
