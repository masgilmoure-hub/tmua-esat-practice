# TMUA 2018–2023 历年卷预估分数

2026-10-13 接入六年逐项换算表。界面统一称为“预估分数”，显示一位小数，并明确“当年官方换算 / 历史尺度”。入口改为“历年真题”，选好年份、试卷和限时方式后直接开始；原有“已准备好”的勾选仅重复确认，没有额外校验或数据保护作用，已删除。替换未完成练习的确认与交卷确认仍保留。

## 来源与核验

原始数据及来源元信息在 `src/data/tmua-score-tables.json`，冻结版本为 `tmua-2018-2023-2026-10-13`。每年 Paper 1 / Paper 2 各 21 个值（0–20），Overall 41 个值（0–40），共 498 个换算值；逐一提取并对照原页，保留零分、满分、非线性转折和封顶值，不插值、不线性拟合。

2018–2022 使用保留 Cambridge Assessment Admissions Testing 作者信息的历史官方换算表镜像；2020–2022 原页另保留机构标识。旧 Cambridge Admissions Testing 站点已经关闭，UAT-UK 的历年题库当前只链接原卷、英文详解和答案表，不直接链接这些旧换算表。因此界面链接明确称为“历史换算表（镜像）”，不把镜像托管方标成官方域名。六份 PDF 原样保存在 `public/score-tables/`，记录各自 SHA-256、页码和实际下载链接。

2023 的 PDF 是 Vantage Admissions 重排文件，作者信息不是 Cambridge。本次以 Cambridge University Press & Assessment **2024-01-10 官方 FOI 回函**独立核对全部 83 个值，一致后才纳入；计算依据为回函，界面直接链接回函，而不是把第三方重排文件冒充官方文档。相关请求为 [TMUA Score Conversion 2023](https://www.whatdotheyknow.com/request/tmua_score_conversion_2023)（Cambridge 引用号 2024/06），数字摘录保存在 `docs/sources/tmua-2023-foi-table.txt`。另外查阅 Christ’s College 保存的 [2023 官方成绩解释](https://www.christs.cam.ac.uk/sites/default/files/inline-files/TMUA%20-%20Explanation%20of%20Results.pdf)，该文档只有分布说明，不从其图形猜测换算值。

六份镜像 URL 和哈希在数据文件中完整保留。可重复验证：

```sh
python scripts/verify-tmua-scores.py
```

需要 Python 3 和 Poppler `pdftotext`。脚本只解析明确列出的六个 PDF 数字和已保存的 FOI 摘录，不执行文档内容；检查文件哈希、完整题数、重复 / 越界、单调性、全部 498 个 JSON 值以及 2023 回函的 83 个值。

## 显示与计算

完整单卷按相应年份的 Paper 1 / Paper 2 表显示单卷预估分数；完整两卷按总答对数 / 40 查 Overall 表。未答与错答均不计为答对，不把单卷原始分倍增或将两单卷换算分取平均。例如 **2023 P1 20/20 + P2 0/20 → Overall 20/40 → 6.2**，而不是 (9.0 + 1.0) / 2 = 5.0。

同样的答对数会因年份不同而换算不同：24/40 在 2018–2021 为 6.5、2022 为 6.7、2023 为 6.8。必须使用所做年份，不能用统一通用表覆盖所有卷。

分数下方展示少 / 多答对 1 道题的查表结果，端点限制在有效原始分范围。例如 2023 总分 20/40 显示 6.2，增减 1 题为 6.0–6.5。**这是原始分变化的敏感区间，不是官方预测区间或统计置信区间**，不人为压窄它。不限时练习另作标注，换算仅供复盘。

只接受内置原卷完整计划：TMUA、整卷模式、支持年份、完整 1–20 原题顺序、正确分卷结构、稳定 ID、来源 URL / 年份 / 原题号和官方答案一致。旧 PDF 快照保留原来题面与标签，符合相同来源和答案即可查表；不改写旧成绩。专项、错题重练、缩短示例、混合年份、未知年份、导入 / 改动 / 缺失 / 重复题不生成分数。此客户端检查是适用条件检查，不是正式考试防作弊措施。

## 与现行分制的区别

核查 [UAT-UK 现行成绩说明](https://esat-tmua.ac.uk/test-results/)：现行考试分析考生响应，使用 Rasch IRT 模型进行题目难度校准与不同卷等值。本站不掌握当前试卷参数或考生群体数据，历史表得到的分数不能直接预测 2026/27 官方成绩，也未实现旧分制向新分制转换。

## 验证与限制

单元测试覆盖六年份关键点、498 个有效值和源文件哈希、2023 回函完整对应、非线性总分、零 / 满分、非法原始分、单卷与不限时、无资格的题集以及旧快照。浏览器覆盖改名与删除确认框、直接开始、实际 20/40 → 6.2、中文 / 英文说明、记录刷新与手机单卷 11/20 → 6.5、错题重练不显示分数。

当前结果、构建和独立预览的实际验收见 [验证记录](validation.md)。没有现行成绩预测、ESAT 评分、账号或跨设备同步；公开 Sites 需另外发布，本轮没有发布工具。Safari / Firefox、真实手机软键盘和屏幕阅读器全套仍未验证。
