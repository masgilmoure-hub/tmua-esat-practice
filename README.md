# TMUA / ESAT practice

面向学生的可操作中英双语练习网站原型。题干始终为英文，解析可选中文、英文或中英对照。

**当前题库为 21 道原创示例 + 320 个 TMUA 原卷题目条目。** 用户上传的 2016–2023 年 16 份原卷和 16 份英文解答已接入：可在答题页直接阅读原题、公式与图表，按题号翻页并作答；题干保留 PDF 原貌，尚未转成可编辑文本。官方题的逐题考点、难度和双语解析尚未补齐；早期样卷暂未导入。见 [站内原卷说明](docs/official-papers.md)。

原创示例有完整双语解析；本版没有官方 1–9 分换算。官方规则与 2026 年 10 月 / 2027 年 1 月考纲于 2026-10-11 核实，见 [规则与考纲来源](docs/exam-rules.md)。支持另外导入审核后的 JSON 题目，仅在当前浏览器保存。

## 运行

需要 Node.js ≥ 22.13（本环境为 24）和 npm。无需后端、数据库或密钥。

```sh
cd /workspace/tmua-esat-practice
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
npm run dev -- --port 5174 --strictPort
```

开发服务为 `http://localhost:5174`。正式构建可部署到任意静态托管服务：

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

如果云环境未提供可访问的端口转发，也可生成**可直接打开的交互式单文件预览**：

```sh
npm run preview:standalone
# 下载 dist/tmua-esat-preview.html 后，在现代浏览器中打开
```

预览文件内置实际构建产物，不依赖 CDN，不是静态截图。`file://` 存储行为取决于浏览器；稳定保存建议使用 HTTP(S) 服务。同一应用在不同网址、端口、浏览器或设备中使用独立记录。

## 已实现

- 七维题库筛选：考试、试卷/科目、知识点、细分考点、原始来源、做题状态、难度，支持联动重置、分页与空状态。基础 / 进阶 / 挑战为教学估计或文件声明；旧数据归入未标注。
- 本地题库工具：JSON 文件或粘贴 → 结构校验 → 来源预览 → 教师复核确认 → 保存；提供原创示例模板、导出和确认移除。重复 ID / 原始来源题号、冲突标签、无效答案、缺失或不对齐双语解析均拒绝整批导入。最多 500 道、1 MB，保存失败不会假报成功。
- 专项训练：当前筛选结果随机抽题，不重复；选择题数、是否限时和分钟数；也能单题练习或重练错题。
- 答题：单选、上一题/下一题、题号导航、待检查标记、交卷确认，提交前不展示解析。
- 官方原卷题库：8 年、320 题，可按来源筛选后单题练习，原卷在答题页内直接渲染。支持单卷 / 两卷、每卷完整 75 分钟或不限时、独立提交与判分、记录和错题重练；未标注考点与难度，不声称已有逐题双语解析。
- PDF 阅读器：内置 16 份用户提供原卷、题号页码定位、翻页与缩放；另支持本地 PDF 上传、IndexedDB 保存、页码校正、确认移除和异常提示。对应 16 份英文解答作为本地资源提供。
- 缩短版示例模考：TMUA 两卷；ESAT Mathematics 1 必选，其他模块可选。各部分独立计时，提交后锁定；超时自动交卷，剩余时间不转移。
- 结果：答对数、以全部题目为分母的正确率、答题用时、未答数、知识点表现与分卷/模块结果。没有官方 1–9 分换算。
- 下一步训练：根据本次错题 / 未答推荐同卷、同知识点训练，优先未做题，每组最多 3 道；无新题时重练本次错题，不据小样本判断掌握程度。
- 复盘：所有选项、正确答案、完整双语步骤、易错点、原始来源和题号；可仅查看错题/未答题。
- 本地记录：自动保存未完成答案、标记、绝对截止时间和题目快照；刷新可续做。按最新一次提交维护错题本，答对后移出；已移除的导入题仍可从历史快照重练；保留最近 200 次提交；清空需确认。
- 存储异常提示：数据损坏或未来版本不会静默覆盖；存储禁用/满时明确说明仅在页面内保留。
- 响应式布局、语义表单、键盘单选、焦点提示和原生可访问确认对话框。

## 检查

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run validate:bank -- examples/question-bank.json
npm run validate:bank -- examples/local-import-demo.json
```

Playwright 使用 Chromium。本云环境已有 `/usr/bin/chromium`；其他机器可运行 `npx playwright install chromium`，或通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定现有浏览器。端到端测试启动 **生产构建**的 4173 预览服务，所以需先执行 `npm run build`。测试输出与截图写入 `/tmp/tmua-esat-playwright`。

测试覆盖筛选/空状态、中英切换、题数与随机抽题、答题/标记/导航、刷新恢复、正确率与未答统计、双语解析、记录持久化、错题纠正、超时自动提交、独立模块计时、确认删除、损坏/写满存储和手机布局。测试数量与实际结果见 [验证记录](docs/validation.md)。

## 结构与后续工作

```text
src/data/         官方规则常量、标签、原创示例题、原卷来源、答案及页码索引
public/papers/    用户上传包内已验证的 16 份原卷与 16 份英文解答
src/features/     题库、模考设置、答题、结果、记录
src/components/   公共界面、导航与确认对话框
src/domain.ts     筛选、组题、计时和成绩逻辑
src/storage.ts    带版本的本地记录校验
src/questionBank.ts / useQuestionBank.ts  共享导入校验与独立题库存储
tests/            逻辑测试与浏览器交互测试
docs/             官方来源、题库规范、设计与验证说明
scripts/          题库 JSON 校验器、单文件预览构建
```

题库格式、原始来源字段与导入约定见 [题库说明](docs/question-bank.md)。本版没有 PDF 自动识别功能；导入工具不会联网验证来源声明、使用权或答案正确性，没有收费、视频或正式账号。没有跨设备同步、教师成绩面板或作业分发；不用于正式安全考试或官方成绩预测。

部分之间的过渡页仅用于原型体验，不代表真实考试允许随意暂停。原创示例数量和难度不足以评估完整考纲掌握情况；官方原卷引用尚未逐题标注考点。记录只在单个浏览器存储，不处理多标签页并发冲突；正式学生/教师端需要服务端身份、权限、数据版本和成绩计算。

每个 Codex 云任务已隔离，使用当前 checkout，无需创建额外 Git worktree。
